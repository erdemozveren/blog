# Hey, I'm Erdem.

I'm a software developer and the founder of **Burjuva Devs LLC**, where I work as an independent developer building software for clients and working on my own products.

I work across frontend, backend, and pretty much anything else a project needs. I don't stick to a particular stack and generally prefer keeping things simple rather than adding complexity for no good reason.

Over the years, I've worked on all sorts of projects, from web applications and developer tools to trading automation platforms. I also spend a fair amount of time experimenting with new technologies and working on side projects.

This blog is where I write about projects I'm working on, technical decisions, problems I've run into, and things worth sharing.

If you want to know more about my experience, you can check out my [CV](https://cv.erdemozveren.com).
